# Lapka Battery для macOS

Приложение показывает заряд двух половинок в строке меню macOS без отдельного окна и значка в Dock. Оно читает USB HID-ответ донгла, описанный в [`документации ZMK`](../../docs/usb-split-battery-zmk.md). Поддерживается macOS 13+.

## Сборка и запуск

Нужны Xcode с инструментами Swift. Из каталога `macos/LapkaBattery` выполните:

```sh
swift test
sh build-app.sh
mkdir -p ~/Applications
ditto dist/LapkaBattery.app ~/Applications/LapkaBattery.app
open ~/Applications/LapkaBattery.app
```

Готовый пакет появится в `dist/LapkaBattery.app`. Перенесите его в `~/Applications` или `/Applications` перед первым запуском, чтобы путь не менялся. При первом запуске приложение регистрирует себя для запуска при входе в macOS. Пункт **«Запускать при входе»** в меню позволяет отключить или снова включить автозапуск. Если macOS требует разрешения, выберите **«Разрешить запуск при входе…»** и включите приложение в системных настройках. Сборочный скрипт подписывает пакет локальной ad hoc подписью; сертификат разработчика Apple не требуется.

В строке меню появится `Л 85% · П 72%`. Тире означает, что донгл не найден, половинка отключена или её заряд ещё не получен. В меню доступны значения по отдельности, перестановка подписей левой и правой половинок, обновление, режим прошивки донгла, управление автозапуском и выход. Порядок слотов определяется порядком сопряжения половинок с донглом.

Чтобы открыть UF2-загрузчик донгла, нажмите **«Режим прошивки донгла…»**, а затем **«Подтвердить: режим прошивки донгла»** в течение 10 секунд. Донгл перезагрузится, USB-клавиатура временно отключится и появится UF2-диск. Приложение не копирует прошивку на диск и не переводит в загрузчик половинки. Пункт работает после установки новой прошивки донгла с поддержкой этой команды.

Если значения не появляются, сначала прошейте новый артефакт **донгла** из GitHub Actions; текущая старая прошивка не содержит дополнительного USB-интерфейса. Затем переподключите донгл и выберите «Обновить».

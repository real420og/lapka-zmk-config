# Lapka Battery для macOS

Приложение показывает заряд двух половинок в строке меню macOS без отдельного окна и значка в Dock. Оно читает USB HID-ответ донгла, описанный в [`документации ZMK`](../../docs/usb-split-battery-zmk.md). Поддерживается macOS 13+.

## Сборка и запуск

Нужны Xcode с инструментами Swift. Из каталога `macos/LapkaBattery` выполните:

```sh
swift test
sh build-app.sh
open dist/LapkaBattery.app
```

Готовый пакет появится в `dist/LapkaBattery.app`. При желании перенесите его в `~/Applications` или `/Applications` и добавьте в **Системные настройки → Основные → Объекты входа** для запуска при входе. Приложение собирается локально и не подписывается сертификатом разработчика Apple.

В строке меню появится `Л 85% · П 72%`. Тире означает, что донгл не найден, половинка отключена или её заряд ещё не получен. В меню доступны значения по отдельности, перестановка подписей левой и правой половинок, обновление и выход. Порядок слотов определяется порядком сопряжения половинок с донглом.

Если значения не появляются, сначала прошейте новый артефакт **донгла** из GitHub Actions; текущая старая прошивка не содержит дополнительного USB-интерфейса. Затем переподключите донгл и выберите «Обновить».
